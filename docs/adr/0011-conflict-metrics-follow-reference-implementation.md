# 衝突指標以參考實作的核心定義為準

## 背景

change `conflict-metrics` 把 `Sub_Module/trajectoryanalyst2` 的衝突指標重寫進 stage3。參考實作的部分定義和文獻不同（逐項分析見 `Sub_Module/trajectoryanalyst2/CONFLICT_METRICS.md`），重寫時可以選擇沿用參考實作，或改成文獻定義。

## 決策

指標的核心定義沿用參考實作，以便結果能和既有分析對照：

- TTC 以中心距離小於 2 m 判定命中（不依類別大小）；MTTC 只在 TTC 有命中時計算。
- 衝突類型依速度夾角分為追撞、變換車道、交叉三類，不另外區分對撞。
- 參考實作稱為 PICUD 的量，實際上是「DRAC 是否大於後車觀測到的最大減速度」；保留這個計算，但改名為**DRAC 超限**，避免和文獻的 PICUD（以間距與反應時間計算）混淆。
- Crash Index 的速度與加速度取向量長度。
- DRAC 與 ΔS 使用中心距離。
- PET 只計算至少同時出現過一幀的軌跡配對。

以下屬於錯誤或缺漏，不算核心定義，仍然修正：單位錯誤（追撞鏈距離門檻原本以像素計算）、最近前後車的分組錯誤、`arccos` 未限制範圍、第一幀速度補 0、衝突類型的整數區間缺口。另外新增的過濾與彙總規則（兩條軌跡都靜止時不配對、起始即重疊不算事件、預設排除行人對行人、低幀率不計算加速度類指標、以事件計數），不改變單一指標的定義。

## 代價

- Crash Index 無法區分加速與減速；中心距離會低估車頭到車尾的實際間距；固定 2 m 的 TTC 門檻對大型車偏寬鬆、對行人偏嚴格；PET 會漏掉「前一方離開畫面後另一方才進入」的情況。這些限制都寫進每個序列 summary 的 `limitations`。
- 依類別大小的 TTC 門檻與不要求同時出現的 PET 保留為選用參數，預設關閉。日後若改採文獻定義，需要重算所有結果並重建 golden 基準。
