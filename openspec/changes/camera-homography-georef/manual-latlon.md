## 怎麼填

查到之後，任選一種方式寫進鏡頭設定：

**方式一：手動填寫**（例如 C000294）

```yaml
latlon: [22.xxxxxx, 120.xxxxxx]
latlon_source: manual
latlon_date: '2026-10-13'
```

把這三行加到 `config/homography/C000294.yaml` 的最後，或直接把座標貼給我，由我寫入。

**方式二：指定路名後重查**（適合路名寫法不同的鏡頭，例如 C000294／C000297）

在鏡頭設定加上：

```yaml
osm_roads: [一心一路, 凱旋三路]
```

然後執行：

```bash
python scripts/geocode_cameras.py --cameras C000294 C000297
python scripts/geocode_cameras.py --apply --accept C000294 C000297   # 確認候選無誤後
```



## 精度要求

- 只用來換算公尺時，精度要求很低：緯度誤差 0.01°（約 1 km）只造成 m/px 約 0.007% 的誤差。
- 要用來下載驗證用底圖、做影像比對時，中心點最好在路口中心 ±20 m 以內，驗證圖與既有底圖（約 88 m 見方）才會有足夠的重疊。
- 目前會用到公尺換算的只有評估資料集中的 C000025、C000043、C000054、C000085，這 4 台都已經有經緯度。上表的 13 台鏡頭中，C000011、C000012、C000033、C000056 只在 Re-ID 來源資料集有影片，其餘 9 台沒有影片，**不填也不影響目前的分析**，可以等日後需要時再補。
